"# PairNext-TCC" 

## Descrição
O PairNext é uma plataforma que conecta clientes a profissionais autônomos da própria região.
Facilita a busca, contratação e contato com profissionais de confiança.
Possui avaliações, portfólio, geolocalização, chat e estimativa de orçamento.

## Tecnologias
- HTML
- CSS
- JavaScript
- PHP
- Banco de Dados (MySQL)
